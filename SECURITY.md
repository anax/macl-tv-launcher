# Security Policy

## ADB Port & Network Security

- **Close ADB after installation**: Leaving port 5555 open over plaintext Wi-Fi exposes your TV to unauthorized connections. Turn off USB debugging and Network debugging on the TV after setup.
- **No Device Identifiers in Commits**: Never commit device serial numbers, private IP addresses, Wi-Fi passwords, or MAC addresses to git history or screenshots.

## Reporting a Vulnerability

If you find a security problem in the launcher, companion add-ons, or setup scripts, please open a private security advisory or contact the maintainers directly.
